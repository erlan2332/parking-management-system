# Parking Management System

Full-stack paid parking management system.

## Tech Stack

- Backend: Java 21, Spring Boot, Gradle
- Frontend: React, TypeScript (planned)
- Database: PostgreSQL (planned)
- Infrastructure: Docker Compose (planned)

## Project Structure

- parking-backend/ - Spring Boot backend
- parking-frontend/ - React frontend (planned)

## Current Status

Initial Spring Boot backend has been created.

Database configuration, frontend and business logic
are not implemented yet.

## Planned Features

- Driver profiles and vehicles
- Parking spot management
- Parking reservations
- Barrier entry and exit simulator
- Day and night tariffs
- Visit and invoice history
- WebSocket real-time updates
- Email notifications

## Development

Requires Java 21.

To compile the backend:

cd parking-backend
./gradlew compileJava

Full database configuration and integration tests
will be added in upcoming development stages.
